## Goal

Build the evaluation harness that every later milestone runs on: deterministic scorers (no model re-runs, no I/O), spend accounting from the ledger (estimation with live pricing fallback and cap enforcement), a Braintrust adapter that replays scored results, and a smoke eval confirming the entire chain works end-to-end. Scorers are plain Python; Braintrust is a destination, never a hard dependency.

---

## Implementation summary

**Five new modules under `dealpoint/eval/`:**

1. **`scorers.py`**: 18 deterministic score functions (gold-seen, citation metrics, fabrication, abstention logic, efficiency fields) over (case, finding, record, canonical_text). Every score is pure Python, no I/O. Returns `None` for "not applicable" (e.g., answer_correct on a CAP_HIT case), never coerces None to False. Includes geometry helpers (range overlap), term parsing for required_evidence (rule 1: tool call to defined-term lookup; rule 2: character overlap in the doc), and a majority-class baseline per question. Tested on real cases including a fabricated quote, a redacted case with an invented quote, and a correct-"No" answer verified not to count as abstention.

2. **`run.py`**: The eval runner: arm × model over one case set (dev/test/counterfactual). Writes canonical result rows to `data/results/{set}_{arm}_{model_slug}_{index_version}_{git_sha7}.jsonl` (one row per case: finding, full execution record, every score, realized cost in USD) plus a summary JSON with aggregates. Supports `--limit N`, `--cases id,id`, `--fake` (offline Haiku smoke without any network or index). Works with no network except OpenRouter and with Braintrust entirely absent. Per-case exception handling ensures one failing case does not abort the sweep.

3. **`braintrust_adapter.py`**: Replays already-computed result rows through `braintrust.Eval()` (spec deliverable 3). Project: `dealpoint-eval`. Experiment name: `{arm}-{slugify(model)}-{index_version}-{git_sha7}`. Metadata: arm, model, index_version, skill_version (None until M4), git_sha, case_set. **Exactly six scores per case** (grounded_accuracy, answer_correct, citation_gold_overlap, citation_verbatim, abstain_correct, skill_adherence); every other computed field goes to metadata. Task function replays stored output verbatim (zero model calls on replay). Scorers read from the replayed output. Dataset push to three `maud-dealpoint-{dev,test,counterfactual}-v1` datasets. Braintrust imported lazily so the offline suite and pyright stay clean when the package or API key is absent.

4. **`spend.py`**: Ledger reading (tolerant: skips corrupt lines), cost estimation, and spend cap enforcement. `read_ledger()` → list of rows; `realized_usd()` sums every row's `usd` field and rounds to 6 places; `fetch_prices()` fetches live OpenRouter pricing with fallback to a pinned table (verified 2026-09-04 for Haiku: input ×1e-6, output ×5e-6 USD/token). `per_case_usd(arm, model)` → (mean_cost, basis_string), uses the ledger's measured mean cost/case per (arm, model) when available, else pinned price × measured mean tokens from a representative execution. Basis strings: `ledger:measured(arm,model)`, `ledger:tokens x <live|pinned:date>`. `estimate(sweep_name)` reads SWEEP_DEFS (four_arm, judges, pareto shapes only) and fills cost via priority: (1) ledger-measured per-case mean, (2) ledger tokens × live pricing, (3) pinned prices × EST_CALLS_PER_CASE. `assert_within_cap(est_usd)` reads `MAX_OPENROUTER_SPEND_USD` from env and raises `SpendCapError` if the cap is unset, unparseable, or would be exceeded by estimated spend.

5. **`smoke.py`**: The M2 smoke: 3 dev cases (contract_0__q01, contract_0__q06, contract_0__q12) on arm B, DEFAULT_MODEL. Idempotent by git_sha7 + index_version: if the result file exists, reuses it and exits 0. Otherwise runs the cases through `dealpoint.eval.run` (real, metered), writes results, exercises the Braintrust adapter path with `no_send_logs=True` (zero score cost). `--send` flag loads the *persisted* results and sends them once to Braintrust with `no_send_logs=False`. Refuses `--send` with an error if the result file is missing (enforcing at-most-one metered smoke). Asserts smoke cost ≤ $0.10 and M1+M2 total ≤ $1.00 (double the $0.50 allocation guide per the spec's Budget Scaling clause).

**Shared infrastructure:**

- **`cases.py`**: Case resolution: `load_case_set(name)` → list of JSONL rows; `find_case(case_id)` → single row across dev/test/counterfactual; `resolve_document_id(case)` (redacted case → its own document; else base agreement); `resolve_question(case)` (in QUESTION_BY_ID or out-of-scope counterfactual); `git_sha7()` and `slugify_model()`. Extracted from `dealpoint/agent/run.py` so both agent and runner use identical case logic.

- **`budget.py`**: CLI tool `python -m dealpoint.eval.budget <sweep_name> [--sample]`. Prints estimate JSON to stdout (nothing else to stdout; diagnostics to stderr). `--sample` runs 3 dev cases for real and adds `sample_est_usd` and `sample_realized_usd` to the estimate, built and unit-tested, never invoked metered in M2.

- **Integration into agent:** `dealpoint/agent/tools.py` wraps each tool (`search_agreement`, `get_section`, `lookup_defined_term`) with a `@_traced()` decorator that lazily imports `braintrust.traced` if available, falling back to a no-op. `dealpoint/llm/client.py` wraps OpenRouter client with `braintrust.wrap_openai` when available. `dealpoint/agent/run.py` imports case logic from `dealpoint/eval/cases` instead of forking it.

**Config additions (`dealpoint/config.py`):**

- `MIN_GOLD_OVERLAP_CHARS = 50`: citation/required_evidence threshold.
- `EVAL_MILESTONE_TAG = "m2"`: ledger tags.
- `M2_SMOKE_CASE_IDS = ("contract_0__q01", "contract_0__q06", "contract_0__q12")`: the three dev cases: direct question, defined-term with required_evidence, gold-"No" (exercises "correct No is not abstention").

- `just smoke [--send]`: smoke gate (no --send) or publish (--send).
- `just budget SWEEP`: `python -m dealpoint.eval.budget` with valid sweep names.
