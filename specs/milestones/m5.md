# M5 — Calibrated multi-judge evaluation (secondary, clearly labelled)

**Authority:** brief §2.5, Appendix C, §6 acceptance 5. **Spend-gated.** Judge scores are never
presented as objective truth.

## Deliverables

1. **Rubrics frozen first** — `eval/judges/rubrics.md`: four dimensions (reasoning/analysis
   quality; evidence sufficiency; trajectory quality *beyond* deterministic adherence; professional
   answer quality), each with five anchored levels. `rubric_version` = hash, stamped into
   `versions.json` **before any judge call**; a test asserts the hash in every judge result equals
   the frozen one.
2. **Blinding** — judge input = question spec, the trace (tool calls, args, retrieved text),
   finding, and — for evidence sufficiency only — the gold span; arm and model names stripped;
   the same blinded packet is what humans score.
3. **Judges** — three heterogeneous families, none from the M6 candidate slate (e.g.
   `openai/gpt-5.6-luna`, `x-ai/grok-4.6`, `qwen/qwen3.8-27b` — verify availability at run time
   and record ids); **one call per trace returning all four dimensions** as JSON.
4. **Subset** — 40 stratified test cases (≈ 3 per question + 4 counterfactual), selection seeded and
   written to `data/eval/judged_subset.json`. Variants judged in M5: arm A @ default model and
   arm D @ default model (M6 adds the other models through the same harness).
5. **Calibration package** — `data/eval/calibration/`: blinded packets for a stratified sample
   across the judged variants (≈ 5 per variant; 10 now, extended to 30 in M6), a scoring form
   (`form.md`) using the identical rubric, and `human_scores.jsonl` schema. `just calibration`
   computes, whenever human scores exist: Spearman ρ and weighted Cohen's κ judge↔human per
   dimension, pairwise judge agreement, and correlation of judged quality with
   `grounded_accuracy`; writes `data/reports/judges.json`. Until human scores exist the report
   carries `"human_calibration": "pending"` and the milestone records the pending input.
6. **Braintrust** — one aggregate (mean-of-judges) score per dimension on the judged subset;
   per-judge scores in metadata.

## Definition of done

- [ ] `gate_m5` offline: blinding strips identities (test); rubric hash check; one-call-four-dims
      parsing with a fake judge; agreement statistics unit-tested on synthetic scores.
- [ ] Spend gate passed; judges run on the 40-case subset for the two M5 variants; `judges.json`
      written with per-dimension aggregates, pairwise judge agreement, correlation with grounded
      accuracy, and `"human_calibration": "pending"`; calibration packets and form written.
- [ ] `specs/mvp/state.json` is NOT edited by the builder; instead the milestone's evidence names
      the pending human input: "score data/eval/calibration/form.md".
- [ ] Full offline suite, `ruff`, `pyright` green.

## Out of scope
Pareto slate runs (M6). No rubric revision after judging without re-running all judges.
