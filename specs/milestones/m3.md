# M3 — Retrieval tournament on dev; freeze arm C

**Authority:** brief §2.3 (tournament), §3 (LlamaIndex only behind the `Retriever` interface),
Appendix A (canonical queries). Engineer's decision: LlamaIndex *may* be used behind the interface
where it materially improves RAG experimentation; custom code owns sections, agent loop, tools,
scorers; gold-span evaluation must never depend on LlamaIndex internals.

## Deliverables

1. **Candidates** behind the `Retriever` Protocol: `DenseRetriever` (M1), `BM25Retriever`
   (`bm25s` or LlamaIndex BM25), `HybridRRFRetriever` (Qdrant sparse+dense RRF, or fusion in
   Python), `RerankRetriever` (hybrid top-20 → cross-encoder `Xenova/ms-marco-MiniLM-L-6-v2` via
   fastembed), optional `MultiQueryFusionRetriever` using **frozen, pre-generated** alternate queries
   stored in `data/eval/tournament_queries.json` (never generated at run time). Chunks are fixed
   (M1 `chunk_version`). If LlamaIndex is adopted, it must fit the ~2 GB disk budget; state the
   installed size in the report.
2. **Tournament** — `dealpoint/eval/tournament.py`: LLM-free; for every dev case, query =
   the question's canonical query (Appendix A) and, as a second harder run, the raw MAUD question
   text; qrels = aligned gold spans; metrics hit@5, hit@10, MRR; per-stage instrumentation showing
   which component surfaced / promoted the gold chunk. Output
   `data/reports/tournament.json` + `tournament.md` (tables), and record wall-clock per config.
3. **Freeze** — the winner's config becomes arm C in `dealpoint/config.py` (`ARM_C_RETRIEVER`),
   its `index_version` written to `data/reports/index_version.txt` and `versions.json`; arms A/B
   keep plain dense over the same chunks.

## Definition of done

- [ ] `gate_m3` offline: every candidate satisfies the Protocol on a synthetic corpus; RRF and
      rerank ordering are unit-tested; the tournament script runs on ≤ 10 dev cases with a tiny
      index inside the test.
- [ ] `data/reports/tournament.json` exists for the full dev set, all candidates, both query
      types; the winner's hit@5 ≥ dense hit@5 on canonical queries; arm C pinned; `index_version`
      recorded and stamped into `versions.json`.
- [ ] Nothing in the tournament reads `data/eval/test.jsonl` (a test greps the module for the path
      and the runner refuses `--set test`).
- [ ] Full offline suite, `ruff`, `pyright` green.
