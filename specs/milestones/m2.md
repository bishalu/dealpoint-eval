# M2 — Eval harness: deterministic scorers, spend accounting, Braintrust adapter, smoke eval

**Authority:** brief §2.1 (case sets are canonical JSONL), §2.4 (metrics), §2.7 (Braintrust
usage and score budget), §3 (scorers are plain Python; Braintrust is a destination).

## Deliverables

1. **Scorers** — `dealpoint/eval/scorers.py`, pure functions over (case, finding, execution record,
   canonical text): `gold_seen`, `gold_first_rank`, `answer_correct`, `citation_verbatim`,
   `citation_gold_overlap` (≥ 50 chars), `fabrication`, `grounded_accuracy`
   (= answer_correct AND citation_gold_overlap), `abstain_correct` (counterfactual: status ==
   ABSTAINED; normal: not abstained), `redacted_fabrication`, `required_evidence_met`,
   `tool_calls`, `cap_hit`, `execution_failed`, plus efficiency fields (tokens, usd, wall_ms).
   Majority-class baseline per question. Unit-tested with synthetic cases including a fabricated
   quote, a redacted case answered with an invented quote, and a correct-"No" answer that must not
   count as abstention.
2. **Runner** — `dealpoint/eval/run.py`: runs an arm × model over a case set, writes canonical
   results to `data/results/{set}_{arm}_{model}_{index_version}_{git_sha7}.jsonl` (one row per
   case: finding, record, scores) and a summary JSON; `--limit N`, `--cases id,id`, `--fake`.
   Works with **no network except OpenRouter** and with Braintrust absent.
3. **Braintrust adapter** — `dealpoint/eval/braintrust_adapter.py`: `braintrust.Eval()` over the
   same runner with project `dealpoint-eval`; experiment name
   `{arm}-{model}-{index_version}-{git_sha7}`; metadata `{arm, model, index_version,
   skill_version, git_sha, case_set}`; **≤ 6 scores per case** (`grounded_accuracy`,
   `answer_correct`, `citation_gold_overlap`, `citation_verbatim`, `abstain_correct`,
   `skill_adherence` — the last returns None until M4) — everything else in metadata;
   `wrap_openai` on the client; `@traced` on each tool. `no_send_logs=True` for smoke runs. Push
   the three case sets as datasets `maud-dealpoint-{dev,test,counterfactual}-v1`.
4. **Spend accounting** — `dealpoint/eval/spend.py`: read the ledger; `estimate(sweep_name)` →
   `{calls, est_usd, per_call_usd, basis}` using current OpenRouter pricing fetched at run time
   (fallback: a pinned price table with its date) and measured mean tokens/case from the ledger;
   `assert_within_cap(est_usd)` reads `MAX_OPENROUTER_SPEND_USD` and raises before any sweep
   starts if `realized + est > cap` or the cap is unset. `python -m dealpoint.eval.budget
   <four_arm|judges|pareto>` prints that JSON; with `--sample` it first runs 3 dev cases, and adds
   `sample_est_usd` and `sample_realized_usd`. The runner calls `assert_within_cap` itself for any
   run > 10 cases.
5. **Recipes** — `just eval ARM MODEL SET [--cases ...]`, `just smoke [--send]` (3 dev cases, Haiku,
   arm B, offline scoring; `--send` logs that one run to Braintrust), `just budget SWEEP`.
6. **Cost accounting per case** — every result row carries realised `usd`; `estimate()` uses the
   ledger's measured mean cost/case per (arm, model) when available, else the pinned price table
   × measured mean tokens; the report shows estimate vs realised for every sweep.

## Definition of done

- [ ] `gate_m2` offline: scorer unit tests (all metrics, incl. the three synthetic traps);
      runner with `--fake` produces result rows with every score field; the majority baseline
      matches `data/eval` labels; `assert_within_cap` raises on unset cap and on overrun.
- [ ] `gate_m2 and needs_model`: `just smoke` passes — **3 dev cases** at Haiku, arm B, 0
      EXECUTION_FAILED, scores computed, `no_send_logs=True`; then the **same 3 results are sent once**
      (`just smoke --send`) so one experiment is visible in Braintrust project `dealpoint-eval` with
      the six scores and the metadata above (name recorded in `data/reports/braintrust_runs.json`).
      No other metered run in M2. M1+M2 realised total ≤ $0.50 (asserted from the ledger).
- [ ] Ledger rows exist for every metered call; `just budget four_arm` prints valid JSON.
- [ ] Full offline suite, `ruff`, `pyright` green.


## Budget scaling (engineer decision, 2026-09-04 — not a spec/brief contradiction)
The whole unattended OpenRouter envelope for M1–M6 is **$4.00** (`MAX_OPENROUTER_SPEND_USD`). Where this spec is smaller than the brief's full-scale design (§2.2, §2.5, §2.6), the scaling below is the engineer's instruction and must be recorded in the report as "budget-scaled", never presented as the full benchmark. Every metered run is sized by `dealpoint.eval.spend.estimate` from measured cost/case in the ledger, and the milestone's own runs must leave headroom for the milestones after it (allocation guide: M1+M2 ≤ $0.50, M4 ≤ $1.50, M5 ≤ $0.60, M6 the remainder).
