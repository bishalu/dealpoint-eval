# M6 — Model cost/quality Pareto experiment

**Authority:** brief §2.6, §6 acceptance 6. **Spend-gated.** Arm D held fixed (frozen index,
skill, tools, cases); only the model varies.

## Deliverables

1. **Slate** (verify availability and tool-calling on 5 dev cases at run time; record exact ids
   and prices in `data/reports/pareto_slate.json`): strong default `anthropic/claude-sonnet-5`
   (already run in M4 — reuse those results, do not re-run); frontier ceiling
   `anthropic/claude-opus-5` (**run last**); cheaper same-family `anthropic/claude-haiku-4.5`;
   fast cross-family Gemini Flash-class (`google/gemini-3.1-flash-lite` unless a cheaper
   Flash-class tool-calling model is available); one reliable open-weight tool-calling model
   (e.g. `deepseek/deepseek-v3.2`). A model that fails tool calling on the 5 dev cases is
   recorded with its failure rate and excluded from the test sweep, not silently swapped.
2. **Sweeps** — arm D on `test` + `counterfactual` per model, each preceded by
   `assert_within_cap`; Opus only after every other model has completed; per-model realised cost
   from the ledger.
3. **Judging** — the M5 harness on the 40-case judged subset for arm D @ each new model (and the
   calibration package extended to ≈ 30 traces across all variants, ≈ 5 per variant).
4. **Report** — `data/reports/pareto.json` + chart (`pareto.svg`/`png`): per model
   `grounded_accuracy`, `abstain_recall`, `execution_failed`, `cap_hit`, judged quality (mean of
   judges, labelled secondary), median/p90 latency, realised $/case, total cost; the Pareto
   frontier identified deterministically. `judges.json` updated with all variants; README results
   section regenerated.

## Definition of done

- [ ] `gate_m6` offline: Pareto-frontier computation unit-tested; report generator tested on fake
      per-model results; slate verification logic tested with a fake client.
- [ ] Spend gate passed; ≥ 4 of 5 models complete on the test set; `pareto.json`, chart, and
      `pareto_slate.json` exist; judged subset covers every completed variant; calibration package
      extended to ≈ 30 packets.
- [ ] README regenerated; every number traceable to a report file (test compares).
- [ ] Full offline suite, `ruff`, `pyright` green.

UI (M7), MCP (M8), any rubric change.
