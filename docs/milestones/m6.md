# M6: model cost/quality Pareto experiment

## Goal

Measure model cost versus quality across the cheap-tier candidate slate to identify efficient frontier points for the agent task, holding system design (arm D: index, skill, tools, cases) fixed and varying only the language model. Results budget-scaled per engineer instruction 2026-09-04 to the frozen 32-case test subset (18 cases at Haiku), not the brief's full-scale design.

## Implementation summary

M6 delivered a complete Pareto frontier analysis across five language models:

- **Slate verification**: Five models verified on 2 dev cases for tool-calling availability; probes recorded in `data/reports/pareto_slate.json`. Haiku and z-ai/glm-5.3-flash reused from M4/M4.1 (decision PD1); deepseek/deepseek-v4-flash chosen over spec's deepseek/deepseek-v3.2 (decision PD2) due to 3× cost reduction; no ceiling anchor run due to envelope constraint (decision PD3). Partial pass attempts (gemini-3.1-flash-lite 14 cases, gpt-5.6-luna-pro 21 cases) stopped and replaced; failures excluded, not swapped.

- **Sweep**: Arm D fixed on frozen test subset (test_subset_v1, 32 cases, rerun on 18 at Haiku). Three new models swept (deepseek, qwen, gemini); per-model realized cost recorded and asserted within ledger-measured bounds. Manifest recorded in `pareto_manifest.json` with git shas and index versions frozen.

- **Judging**: M5 harness on 12-case judged subset for arm D at each completed model (6 variants: A@Haiku, D@Haiku reused, D@GLM reused, D@Deepseek, D@Qwen, D@Gemini; 18 cases × 3 judges × 6 variants = 324 rows, 0 failed). Calibration packets extended in `data/eval/calibration/packets.jsonl` and form.md to cover every judged trace.

- **Report and frontier**: Pareto analysis computed deterministically with rule: minimize realized $/case, maximize grounded_accuracy. Frontier identified as qwen/qwen3.7-flash and deepseek/deepseek-v4-flash; no ceiling model measured means a stronger, more expensive model could sit above every point. Frontier scoped to cheap tier only (brief_difference 3). Results table with per-model grounded_accuracy (objective), abstain_recall, execution_failed, cap_hit, judged_quality (secondary, model-judged), median/p90 latency, $/case, total cost in `data/reports/pareto.json` and chart (`pareto.svg`). README `<!-- BEGIN PARETO -->` block regenerated; `<!-- BEGIN RESULTS -->` (M4) frozen untouched.

- **Spend ledger and reconciliation**: Every M6 call tagged with `milestone_tag: m6`; non-case-run probes tagged `purpose: probe`. Sweep spend $0.630336, judge $0.077565, probe $0.034754 = $0.742655 total. Hard assertion in pareto_report.py:963-981 ensures every sweep dollar maps to a completed model or partial_runs entry (gemini initial pass $0.062627 superseded, gpt pass $0.283390 stopped). Envelope remaining: $0.38606 of $4.00.

4. **Judged quality secondary**: All 324 judge rows are from three models, not all five (per judged subset size); judges are out-of-family from the agent's trained models; scores are labeled model-judged and secondary throughout (pareto.json, pareto.md).

5. **Partial runs reported but not scored**: Gemini initial 14-case and GPT 21-case attempts stopped; spend recorded, model excluded from results table, counts listed separately.
