# M1 — Agent foundation: canonical sections, chunks, dense index, three tools, bounded loop

**Authority:** `specs/grilled-product-brief.md` §1.2 (finding schema + execution record), §1.3
(tools, cap 8), §2.2 arm A/B definitions, §3 (stack), §3.4 (chunking), §3.5 (layout).

## Deliverables

1. **Corpus** — `dealpoint/corpus/`:
   - `document.py`: load a canonical document (original or redacted variant) with its section map
     from M0.1's derived files; expose `text`, `sections`, `get_section(ref)`, and
     `defined_term(term)` (regex over `"Term" means|shall mean|has the meaning …`, tolerant of
     quote style, case, and `Company Material Adverse Effect`-style prefixes; returns the block
     with canonical offsets).
   - `chunks.py`: section-bounded retrieval chunks, sub-split at ~400 tokens / 50 overlap, each
     `{agreement_id, chunk_id, section_ref, start, end, text}`; deterministic; chunking params
     hashed into `chunk_version`.
   - `retrievers.py`: `Retriever` Protocol — `search(agreement_id, query, k=5) -> list[Chunk]` —
     and `DenseRetriever` over **Qdrant local mode** (`qdrant-client[fastembed]`, on-disk under
     `data/index/`), embeddings `BAAI/bge-small-en-v1.5`. Index the 20 selected agreements and the
     30 redacted variants. `index_version` = hash(chunk_version, embedding model, retriever config),
     written to `data/reports/index_version.txt` and `data/reports/versions.json`.
2. **LLM client** — `dealpoint/llm/client.py`: `openai` SDK against OpenRouter, native tool
   calling, `extra_body={"usage": {"include": True}}` on every call so realised USD is captured;
   every metered call appends `{ts, milestone_tag, model, calls:1, usd, input_tokens,
   output_tokens}` to `data/results/spend_ledger.jsonl`. A `FakeClient` for offline tests that
   replays scripted tool calls and a final structured answer.
3. **Agent** — `dealpoint/agent/`:
   - `schema.py`: the public finding (`answer` ∈ question options ∪ `ABSTAIN`; 1–3 `evidence`
     `{section_ref, quote}`; `rationale ≤ 80 words`) and the internal execution record
     (`status` ∈ ANSWERED | ABSTAINED | CAP_HIT | EXECUTION_FAILED, `failure_reason`,
     `trajectory[]` with tool, args, returned chunk ids/char ranges, `usage`, `wall_ms`).
   - `tools.py`: `search_agreement`, `get_section`, `lookup_defined_term` — pure functions over the
     corpus + a `Retriever`; each returns text with `section_ref` and canonical offsets.
   - `loop.py`: one agent, native tool calling, **hard cap 8 tool calls → CAP_HIT**; structured
     final output via JSON schema; schema-invalid → one retry then EXECUTION_FAILED; API errors →
     3 retries with backoff then EXECUTION_FAILED. Quotes are normalised with the M0 canonicaliser
     before any verbatim check.
   - `pipeline.py`: **arm A** — no loop: dense top-5 chunks → one call → finding.
   - `prompts.py`: the question spec block shown to the model in **every** arm (MAUD question,
     gloss, exact option strings, output schema). No skill content here (M4).
4. **CLI** — `python -m dealpoint.agent.run --case <case_id> --arm A|B --model <id>` prints the
   finding + execution record as JSON; `--fake` uses the FakeClient.
5. **Dependencies** — add optional groups `agent` (`openai`) and `retrieval`
   (`qdrant-client[fastembed]`) to `pyproject.toml`; install them. Disk is ~2 GB free: no torch,
   no LlamaIndex here.

## Definition of done

- [ ] `gate_m1` offline tests (FakeClient): tool loop terminates; cap → CAP_HIT; schema-invalid →
      retry → EXECUTION_FAILED; ABSTAIN path; verbatim normalisation; `get_section` and
      `lookup_defined_term` on a synthetic document and on one real selected agreement
      (`Material Adverse Effect` resolves).
- [ ] `gate_m1 and needs_model` smoke: 3 dev cases (one defined-term question among them), arm B,
      `anthropic/claude-haiku-4.5` → 0 EXECUTION_FAILED, every ANSWERED finding has ≥ 1 quote that
      is a verbatim substring of the canonical text, ledger gained 3+ rows with `usd > 0`.
- [ ] Dense index built for 20 + 30 documents; `index_version.txt` written; a test asserts a
      `search_agreement` on a dev case returns a chunk overlapping its gold span for at least
      one of 5 sampled dev cases (retrieval sanity, not a quality gate).
- [ ] Full offline suite, `ruff`, `pyright` green.

## Out of scope
